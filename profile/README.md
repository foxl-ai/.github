## Agents for the rest of us

Agents today are built for the people who build agents: a terminal, an API key, a
configuration file, and a new vocabulary to learn before anything useful happens.

We think the agent should come to you instead. It belongs where the work already
is, with your files, your browser, and your meetings, and it should keep going
while you are away and then tell you plainly what it did.

That is the barrier we are taking away. Not the model and not the tooling, but
the distance between an ordinary person and work that is finished.

## What we build

| | | |
| :--- | :--- | :--- |
| **Desktop** | Think it through. Put it to work. Your agent runs on your own computer, with the files, browser, and permissions you give it. | [foxl.ai][web] |
| **Notes** | Keep the conversation. Record a meeting, follow the transcript, and leave with a summary you can return to. | [foxl.ai/notes][notes] |
| **Code** | Give the task some room. Cloud agents take a task and hand back a pull request. Private beta. | [foxl.ai/code][code] |

One version number, one changelog, three products that share the same agent.

## The ideas behind Foxl

Good software should leave you more room for the work that matters.

- **Make room for attention.** One calm workspace, with detail available as the work calls for it.
- **Keep you in control.** You choose the model and the permissions, and you can see what your agent is doing.
- **Let context carry forward.** Memory stays yours to read and edit, as plain Markdown on your own machine.
- **Respect your choices.** An account you already have, a provider API key, or a model running on your own hardware.

## Get started

```sh
brew install --cask foxl-ai/tap/foxl
```

Or take the direct download for [macOS][macos], [Windows][windows],
[Linux][linux], [iPhone and iPad][ios], or [Android][android]. Nothing to
install to try it in a browser: [app.foxl.ai][app].

## Open at the edges

Foxl is proprietary software. The parts that ask for access to your machine are not.

| Repository | What it is |
| :--- | :--- |
| [**foxl**](https://github.com/foxl-ai/foxl) | Releases and downloads for every platform |
| [**skills**](https://github.com/foxl-ai/skills) | The skill library your agent installs from. MIT-0 |
| [**browser-extension**](https://github.com/foxl-ai/browser-extension) | Lets the agent work in your real Chrome tabs. Apache-2.0 |
| [**homebrew-tap**](https://github.com/foxl-ai/homebrew-tap) | The Homebrew cask, published by the release pipeline |
| [**signal-cli**](https://github.com/foxl-ai/signal-cli) | A small Signal CLI in Rust, with MCP support |
